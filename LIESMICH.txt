BookmarkHub 2.1.0 - selbst gehosteter Lesezeichen-Manager
==========================================================

Starten / Aktualisieren:   docker compose up -d --build
Adresse:                   http://<host>:3131      (Status: /healthz)
Daten:                     ./data     (users.json, bookmarks.json, categories.json, meta.json,
                                       .session-secret, favicons/)
Sicherungen:               BACKUP_PATH aus .env (Standard ./backups), taeglich, 14 + 8 woechentlich
Passwort vergessen:        docker exec -it bookmarkhub reset-admin-password
                           --random        Einmal-Passwort ausgeben
                           --user NAME     anderer Benutzer
                           --disable-2fa   Zwei-Faktor-Anmeldung abschalten (--keep-password: Passwort bleibt)
                           oder Datei data/RESET_ADMIN_PASSWORD anlegen und Container neu starten
                           (Einmal-Passwort steht dann im Container-Log).
Im Container gibt es nur sh (kein bash).

Ausfuehrliche Anleitung, Aenderungen, Pruefung und Ideen: ../docs/*.html

Entwicklung:
  npm install && (cd server && npm install)
  npm run build && npm start          -> http://localhost:3131
                                         (build prueft zuerst alle 33 Sprachdateien)
  npm run dev  (Vite auf :8080, leitet /api an :3131 weiter)
  npm test     (Server-Tests, Node >= 20)
  tests/ui-test.mjs       Oberflaechen-Test mit Playwright (WebKit iPhone DPR 3, dunkel, RTL, DSGVO)
  tests/favicon-rate.js   Favicon-Trefferquote alt/neu

Aufbau:
  src/          React-Oberflaeche (Vite, Tailwind, dnd-kit), src/i18n/<sprache>.json
  public/       statische Dateien (Logo, Icons, Manifest, Service Worker)
  server/       Express-Server: API, Sicherungen, Favicons, Link-Pruefung, 2FA, Passwort-Reset, Tests
  scripts/      check-i18n.mjs (Uebersetzungspruefung)
  docker/       Entrypoint und reset-admin-password-Wrapper
